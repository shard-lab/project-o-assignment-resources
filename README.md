# Project O Assignment Resources

Project O 제품 과제에 제공되는 참고 자료입니다. 과제 안내문을 기준으로 사용해 주세요.

**[브라우저에서 자료 보기](https://project-o-assignment-resources.vercel.app)**

`fixtures.json`만 필요하면 [여기서 바로 받으세요](https://project-o-assignment-resources.vercel.app/fixtures.json).

## 포함된 자료

- `index.html` — 현재 퍼널, 모바일 참고 화면, 고정 조건과 공식 자료
- `fixtures.json` — 지갑·잔액·quote·transaction·event 합성 fixture

`fixtures.json`은 실제 사용자 데이터, API 계약 또는 테스트넷 증거가 아닙니다.

## 시작하기

1. 상단의 **Use this template**을 선택합니다.
2. **Create a new repository**를 선택합니다.
3. 새 저장소를 **Private**으로 설정합니다.
4. 생성된 저장소에서 과제를 진행합니다.

Public 저장소를 Fork하면 제출 작업도 공개될 수 있으므로 Fork 대신 Template을 사용해 주세요.

로컬에서는 `index.html`을 브라우저로 열면 됩니다. 별도 설치나 서버는 필요하지 않습니다.
